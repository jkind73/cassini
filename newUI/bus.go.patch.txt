Patch for bus.go
=================

Two independent additions, both additive -- neither changes existing
4MB-RAM-cart or no-cart behavior at all.

Provenance:
  - ramCartID1MB = 0x5A: SegaXtreme community reverse-engineering
    thread citing Charles MacDonald's Saturn hardware docs and
    yabause's own source (cross-checked against this codebase's
    existing ramCartID4MB = 0x5C, which the same source independently
    confirms).
  - ROM cart addressing (0x02000000-0x021FFFFF, no hardware ID byte,
    detection is via the game reading its own data directly): supplied
    directly by the project owner, cross-checked for internal
    consistency against everything above (the window sits below
    extRAMBase=0x02400000, non-overlapping with the RAM cart's range,
    consistent with these being mutually-exclusive physical devices in
    the same slot).
  - Product numbers / cart-requirement list: Ymir project issue #98
    (github.com/StrikerX3/Ymir/issues/98), itself citing Mednafen's
    cart database; KOF96's specifically cross-checked against
    satakore.com's independent game database.
  - ROM cart file identity (KOF95/Ultraman): Mednafen/Beetle Saturn's
    own filenames and MD5 hashes, quoted in Ymir issue #71
    (github.com/StrikerX3/Ymir/issues/71). MD5, not the CRC32+SHA1
    MAME convention the rest of cassini's hash identification follows
    (biosdb, hashid) -- this is a narrower, separate database (see the
    new romcartdb package) and I don't have CRC32/SHA1 for these two
    specific dumps verified from any source, so it stores what's
    actually confirmed rather than computing/guessing the others.

--- 1. New constants, alongside the existing cart ones ---

const (
	ramCartIDNone = 0xFF
	ramCartID4MB  = 0x5C
+	ramCartID1MB  = 0x5A
	...
	extRAMBase = 0x02400000
	extRAMTop  = 0x027FFFFF
	extRAMSize = 4 * 1024 * 1024
	extRAMMask = extRAMSize - 1
+	ram1MBSize = 1 * 1024 * 1024
+	ram1MBMask = ram1MBSize - 1
+
+	// ROM cartridge window (KOF '95 / Ultraman: Hikari no Kyojin
+	// Densetsu). Distinct address range from the DRAM cart above and
+	// mutually exclusive with it. No hardware ID byte is involved;
+	// the game detects the cart by reading its data directly and
+	// validating headers/tables it expects to find there.
+	romCartBase = 0x02000000
+	romCartTop  = 0x021FFFFF
)

--- 2. New Bus field and setter, alongside the existing extRAM field ---

type Bus struct {
	...
	extRAM    []byte // 4 MB Extended RAM Cartridge (A-Bus CS0)
	ramCartID uint8
+	romCart   *ROMCartridge // non-nil when a ROM cartridge (not a DRAM
+	                        // cart) is inserted; mutually exclusive
+	                        // with ramCartID being anything other than
+	                        // ramCartIDNone -- SetROMCartridge and the
+	                        // existing RAM-cart setup are expected to
+	                        // be used exclusively of each other by
+	                        // whatever loads a disc's cart requirement
+	                        // (see romcartdb wiring).
	...
}

+// SetROMCartridge installs a ROM cartridge (KOF95/Ultraman). Pass nil
+// to remove it. Setting a ROM cartridge does NOT automatically clear
+// ramCartID -- the caller (emulator.go's disc-load path) is
+// responsible for setting ramCartID to ramCartIDNone at the same
+// time, since these two cart types are mutually exclusive on real
+// hardware and cassini has no way to enforce that invariant from
+// inside Bus alone without knowing which one the caller intends.
+func (b *Bus) SetROMCartridge(cart *ROMCartridge) {
+	b.romCart = cart
+}

--- 3. ramCartAddrMask helper, used by all 6 read/write handlers below ---

+// ramCartAddrMask returns the address mask for the currently-inserted
+// DRAM cart, so a 1MB cart correctly mirrors every 1MB across the
+// (always 4MB-sized) address window rather than being read with a
+// fixed 4MB mask that would index past a would-be 1MB backing store
+// -- matching real hardware, where a smaller cart's unconnected upper
+// address lines cause this exact aliasing.
+func (b *Bus) ramCartAddrMask() uint32 {
+	if b.ramCartID == ramCartID1MB {
+		return ram1MBMask
+	}
+	return extRAMMask
+}
